Returns all available fields for contacts and companies, grouped by entity.
Use this endpoint to discover field names before upserting contacts or companies.

## Field sources

| Source | Description |
|--------|-------------|
| `default` | Built-in fields available on every account (e.g. email, firstName, phone) |
| `custom` | Custom fields created by your team, in the app or with [Create or Update Field](/api-reference/endpoints/fields/create-field). A `select` field carries its `options`. |
| `crm_synced` | Fields your CRM field mapping includes that are neither default nor custom fields (e.g. leadStatus) |

## CRM-mapped fields

Each field is listed once. When your team has a CRM connected, a field the field mapping between lemlist and your CRM includes carries an additional `crmField` property: the name of the field on the CRM side. This goes for default, custom and `crm_synced` fields alike.

If no CRM is connected, no field carries `crmField` and no `crm_synced` fields are returned.

## Filtering

Use query parameters to narrow results:
- **`entity`** — return fields for a single entity (`contact` or `company`)
- **`source`** — return only fields from a specific source (`default`, `custom`, or `crm_synced`)

Both filters can be combined.
