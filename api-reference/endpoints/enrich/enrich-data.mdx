---
title: Enrich Data
openapi: post /enrich
description: Enriches data by finding emails, phone numbers, or LinkedIn information from various inputs.
---

The API provides the ability to request data (email, phone number, LinkedIn information) in multiple ways:

- Given some input (email, LinkedIn URL, etc.) for a single enrichment, with this endpoint
- For a lead already in lemlist, with [Enrich Lead](/api-reference/endpoints/enrich/enrich-lead)
- Many at once, with [Bulk Enrich Data](/api-reference/endpoints/enrich/bulk-enrich-data)

All enrichment APIs are asynchronous: they answer with an enrichment `id` and the work runs in the background. There are two ways to retrieve your enriched data:

1. **Webhooks (recommended)**: receive an `enrichmentDone` or `enrichmentError` event as soon as the enrichment is over, on your team's webhooks and on the `webhookUrl` passed here. See [Enrichment webhooks](/api-reference/objects-definitions/enrich#webhooks).
2. **Polling**: call [Get Enrichment Result](/api-reference/endpoints/enrich/get-enrichment-result) with the `id`.

<Warning>
Every call starts a new enrichment and uses credits, even when the same person was enriched before.
</Warning>

When the enrichment cannot be started, the answer carries a `code` and a `message`: see [Request errors](/api-reference/objects-definitions/enrich#request-errors).
