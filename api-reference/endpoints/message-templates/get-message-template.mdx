<SnippetObjectReference objectName="Message template" objectPath="message-template" />

The body is HTML as stored, with `{{variables}}` left raw: keep them as they
are when reusing the template in a step.

<Note>
A deleted template, another workspace's template and a campaign step body all
answer `404 EMAIL_TEMPLATE_NOT_FOUND`: only the team library is readable here.
</Note>
