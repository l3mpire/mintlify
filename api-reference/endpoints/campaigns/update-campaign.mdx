<Warning>
The settings fields of this endpoint are deprecated. They still work, but use
[Update Campaign Settings](/api-reference/endpoints/campaigns/update-campaign-settings)
instead: it covers all the settings, and refuses an unknown or invalid field
instead of ignoring it.
</Warning>

`sendUserIds` replaces the sender pool and keeps the first account of each channel type for each sender. To add a sender without a replacement, or to pick a mailbox, a WhatsApp account or an alias, use the [Senders](/api-reference/endpoints/senders/get-campaign-senders) endpoints.
