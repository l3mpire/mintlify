openapi: get /campaigns/{campaignId}/settings
description: Returns all the settings of a campaign.
---

<SnippetObjectReference objectName="Campaign Settings" objectPath="campaign-settings" />

<Note>
This endpoint requires at least the **Email Pro** plan.
</Note>

The response is not wrapped in `data`.

- `general.labels`, `general.sequenceId`, `senders.espRouting` and
  `schedule.scheduleIds` are read-only.
- `senders.espMatching` gives the team value when the campaign does not set it.
- A campaign hidden from the user of the API key answers `404`. An API key not
  linked to a user acts as the first user of the team.
