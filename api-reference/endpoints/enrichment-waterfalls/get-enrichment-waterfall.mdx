---
openapi: get /v2/enrichments/waterfalls/{waterfallId}
description: Returns one enrichment waterfall of your team, default or custom.
---

A waterfall is addressed by the id returned by [List Enrichment Waterfalls](/api-reference/endpoints/enrichment-waterfalls/list-enrichment-waterfalls): `default_email` or `default_phone` for a default waterfall, an `ecw_` id for a custom one.
