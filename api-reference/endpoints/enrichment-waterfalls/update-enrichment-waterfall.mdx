---
openapi: patch /v2/enrichments/waterfalls/{waterfallId}
description: Updates the name, provider order or countries of an enrichment waterfall.
---

Only the fields you send change. When `providers` is sent it replaces the whole order; providers you leave out are appended, disabled. On a default waterfall this takes over from the lemlist order: `editor` becomes your user id and the list is followed as is. Use [Reset Enrichment Waterfall](/api-reference/endpoints/enrichment-waterfalls/reset-enrichment-waterfall) to hand it back to lemlist.

`conditions` is accepted on custom waterfalls only and replaces the whole country list. Countries you remove go back to the default waterfall; countries you add must not belong to another custom waterfall of the type.

## Error codes

| Code | Status | Cause |
| ---- | ------ | ----- |
| `ROUTE_BAD_REQUEST` | 400 | Malformed body, or `name` empty or longer than 100 characters. |
| `ENRICHMENT_WATERFALL_EMPTY_UPDATE` | 400 | The body is empty. |
| `ENRICHMENT_WATERFALL_UNKNOWN_PROVIDER` | 400 | A `providers[].id` is not available to your team for this `type` (unknown, or external and not connected — see [Connect Provider](/api-reference/endpoints/enrichment-providers/connect-provider)). |
| `ENRICHMENT_WATERFALL_DUPLICATE_PROVIDER` | 400 | The same provider id appears twice. |
| `ENRICHMENT_WATERFALL_NO_ENABLED_PROVIDER` | 400 | `providers` has no enabled entry. |
| `ENRICHMENT_WATERFALL_INVALID_COUNTRY` | 400 | A `conditions.country.in` entry is not an ISO 3166-1 alpha-2 code. |
| `ENRICHMENT_WATERFALL_CUSTOM_WITHOUT_CONDITION` | 400 | `conditions.country.in` is empty. |
| `ENRICHMENT_WATERFALL_DEFAULT_HAS_NO_CONDITION` | 400 | `conditions` was sent for a default waterfall. |
| `ENRICHMENT_WATERFALL_COUNTRY_CONFLICT` | 409 | A country already belongs to another custom waterfall of this type. |
| `ENRICHMENT_WATERFALL_DUPLICATE_NAME` | 409 | Another waterfall of this type has this name, or the name is a default waterfall name (a default may keep its own). |
