---
openapi: get /team/roles
description: Lists the roles an invitation may carry, with the id Invite Team Members takes.
---

Use it to turn a role name ("SDR", "Manager") into the `rol_...` id that [Invite Team Members](/api-reference/endpoints/team/invite-team-members) expects. `needsApproval` tells which roles wait for the team's admins to confirm the invitation.
