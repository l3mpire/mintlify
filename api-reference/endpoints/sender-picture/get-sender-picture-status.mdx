<Note>
Omit `userId` to read your own mailboxes. A teammate's `userId` must belong to your team, otherwise the call answers `403` with the code `SENDER_PICTURE_USER_NOT_IN_TEAM`. Only active mailboxes assigned to that user in your team are listed.

When `hasPicture` is `false`, the user has no lemlist profile picture: every sync is refused until they upload one in Settings > Account.
</Note>
