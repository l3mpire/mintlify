Use this endpoint to:

- Edit the message content or subject of the step
- Change the delay before this step executes
- Update the title and the priority of the task the step creates
- Switch a channel step between automatic sending and a manual task
- Change method/URL (for API steps)
- Adjust delay logic for conditional steps

<Warning>
You **cannot** change the `type` of a step (e.g., from `email` to `linkedinInvite`). To do so, delete the step and create a new one.
However, you **need** to add the `type` field in the request body even if you can't modify it...
</Warning>

<Warning>
This endpoint refuses any condition step that has **more than one branch** besides Else, with
`400 Multi-branch conditions cannot be edited via the API yet.` — its rebuild would collapse the step
back to a single branch plus Else and silently drop the others.

To change the condition key of such a step, remove branches with
[`DELETE …/branches/{branchSequenceId}`](/api-reference/endpoints/sequences/delete-condition-branch)
until one is left, then patch it here. To change what one branch tests without touching the others,
use [`PATCH …/branches/{branchSequenceId}`](/api-reference/endpoints/sequences/update-condition-branch)
instead.
</Warning>


## Running campaigns

Editing a step does not require pausing the campaign. The new content applies to the sends that
follow: a lead who already received that step keeps the version that was sent to them, and a lead
who has not reached it yet gets the edited one.

A refusal carries a `code` in the body next to the message, so a rejected edit can be told apart
from a transport failure.


## Manual steps

`manual` switches a channel step between automatic sending and sending once a task is marked done,
as described in [Add Step](/api-reference/endpoints/sequences/add-step-to-sequence#manual-steps). It
takes the same step types, and `type` must be the step's own. A switch, like a new `title` or
`priority`, applies to the tasks created afterwards: a lead whose task for this step already exists
keeps it as it is.

```json
{
    "type": "email",
    "manual": true,
    "title": "Review the follow-up",
    "priority": 1
}
```

Send `"manual": false` to switch the step back to automatic sending:

```json
{
    "type": "email",
    "manual": false
}
```

A priority cannot be removed once set: `null` is rejected with `400 Invalid request body`.

## Enrichment steps

The workflows of an `enrichment` step cannot be edited here. A valid `workflowIds` is accepted but
ignored: the call answers `200` and the step keeps its workflows. To change them before leads enter the
campaign, delete the step and add a new one.

## End sequence steps

`endLeadStatus` is the only setting of an `endSequence` step. It is read when a lead reaches the
step: a change applies to every lead that reaches it afterwards, including a paused lead waiting on
it. The step's `delay` stays `0`: any other value answers `400 Invalid request body`.

```json
{
    "type": "endSequence",
    "endLeadStatus": "interested"
}
```

## Supported Step Types

| Type | Editable Fields | Description |
| --- | --- | --- |
| `email` | `subject`, `message`, `delay`, `manual`, `title`, `priority` | Sends an email to the lead |
| `manual` | `title`, `message`, `delay`, `priority` | Manual task to be performed by the user |
| `phone` | `message`, `delay`, `title`, `priority` | Reminder to make a phone call |
| `api` | `method`, `url`, `delay` | Makes an API call |
| `linkedinVisit` | `delay` | Simulates a profile visit on LinkedIn |
| `linkedinInvite` | `message`, `altMessage`, `images`, `videos`, `delay`, `manual`, `title`, `priority` | Sends a LinkedIn invite with message |
| `linkedinSend` | `message`, `altMessage`, `altMessagePremium`, `images`, `videos`, `delay`, `manual`, `title`, `priority` | Sends a LinkedIn message |
| `linkedinInMail` | `subject`, `message`, `delay`, `manual`, `title`, `priority` | Sends a LinkedIn InMail, from a Premium or Sales Navigator sender only |
| `linkedinVoiceNote` | `message`, `altMessage`, `delay`, `recordMode`, `manual`, `title`, `priority` | Sends a LinkedIn voice note. Audio is either recorded manually or AI-generated from a text template, depending on `recordMode` |
| `linkedinFollow` | `delay` | Follows the lead on LinkedIn |
| `linkedinLikeLastPost` | `delay` | Likes the lead's most recent LinkedIn post |
| `linkedinCommentLastPost` | `delay` | Posts an AI-generated comment on the lead's most recent LinkedIn post |
| `linkedinEndorse` | `delay`, `skillName`, `endorseAnyFallback` | Endorses a skill on the lead's LinkedIn profile |
| `linkedinWithdrawInvitation` | `delay` | Withdraws a pending LinkedIn invite |
| `sendToAnotherCampaign` | `campaignId` | Sends the lead to another campaign |
| `conditional` | `conditionKey`, `delayType`, `delay`, `customField`, `customOperator`, `customValue` | Triggers the next step based on lead behavior |
| `whatsappMessage` | `message`, `delay`, `manual`, `title`, `priority` | Sends a WhatsApp message |
| `sms` | `message`, `delay`, `manual`, `title`, `priority` | Sends an SMS to the lead |
| `enrichment` | `delay` | Enriches the lead. See [Enrichment steps](#enrichment-steps) above |
| `endSequence` | `endLeadStatus` | Ends the lead in the campaign. See [End sequence steps](#end-sequence-steps) above |

## Request Body

Only include the fields you want to update. Required fields are not enforced here.

| Field | Type | Applies To | Description |
| --- | --- | --- | --- |
| `subject` | string | `email`, `linkedinInMail` | Email or InMail subject line. On `linkedinInMail`, a blank one is saved but blocks the campaign launch. Maximum 400 characters (applied to the raw template, including any Liquid syntax) |
| `message` | string | `email`, `linkedin*`, `manual`, `phone`, `whatsappMessage`, `sms` | Message text. Pass an empty string to clear it (ignored on `manual` and `phone` steps) |
| `altMessage` | string | `linkedinInvite`, `linkedinSend`, `linkedinVoiceNote` | The premium invitation note on an invite, the out-of-network note on the other two. Pass an empty string to clear it. See [LinkedIn invitation notes](/api-reference/endpoints/sequences/add-step-to-sequence#linkedin-invitation-notes) on Add Step |
| `altMessagePremium` | string | `linkedinSend` | The premium variant of the out-of-network note. Pass an empty string to clear it. See [LinkedIn invitation notes](/api-reference/endpoints/sequences/add-step-to-sequence#linkedin-invitation-notes) on Add Step |
| `title` | string | `manual`, `phone`, a channel step with `manual: true` | Title of the task the step creates. Maximum 100 characters |
| `manual` | boolean | `email`, `linkedinInvite`, `linkedinSend`, `linkedinInMail`, `linkedinVoiceNote`, `whatsappMessage`, `sms` | `true` turns the step into a task, `false` switches it back to automatic sending. See [Manual steps](#manual-steps) above |
| `priority` | integer | `manual`, `phone`, a channel step with `manual: true` | Priority of the task the step creates: `0` low, `1` medium, `2` high |
| `method` | string | `api` | One of `GET`, `POST`, `PUT`, `DELETE`, `PATCH` |
| `url` | string | `api` | Valid HTTP/HTTPS URL |
| `delay` | integer | all except `sendToAnotherCampaign` and `endSequence` | Delay before this step, in days. Must be between 0 and 1500 |
| `delayType` | string | `conditional` | One of `within`, `waitUntil` |
| `conditionKey` | string | `conditional` | See supported condition keys below |
| `customField` | string | `conditional` keyed `customLeadInfo` | The field to test. A bare name reads as a lead variable (`jobTitle` becomes `variables.jobTitle`); prefix with `fields.` for a contact field; a company field is written `company.<field>` (`companyName` is stored as `company.name`) |
| `customOperator` | string | `conditional` keyed `customLeadInfo` | One of `equal`, `contains`, `empty`, `notEmpty` |
| `customValue` | string | `conditional` keyed `customLeadInfo` | The value the field is compared to. Required for `equal` and `contains`, refused for `empty` and `notEmpty` |
| `campaignId` | string | `sendToAnotherCampaign` | ID of destination campaign |
| `leadAction` | string | `sendToAnotherCampaign` | What happens to the lead in the source campaign once it has been moved. One of `continue`, `pause`, `stop`. See [What happens to the transferred lead](/api-reference/endpoints/sequences/add-step-to-sequence#what-happens-to-the-transferred-lead) on Add Step |
| `endLeadStatus` | string | `endSequence` | The status the lead shows once the step ends it. One of `completed`, `interested`, `notInterested`. See [End sequence steps](/api-reference/endpoints/sequences/add-step-to-sequence#end-sequence-steps) on Add Step |
| `images` | array of strings | `linkedinInvite`, `linkedinSend` | Public HTTPS URLs of images to attach. Replaces the step's current images — pass `[]` to clear them. See the [LinkedIn media constraints](/api-reference/endpoints/sequences/add-step-to-sequence#linkedin-media-constraints) on Add Step |
| `videos` | array of strings | `linkedinInvite`, `linkedinSend` | Public HTTPS URLs of videos to attach. Replaces the step's current videos — pass `[]` to clear them. See the [LinkedIn media constraints](/api-reference/endpoints/sequences/add-step-to-sequence#linkedin-media-constraints) on Add Step |
| `skillName` | string | `linkedinEndorse` | Name of the LinkedIn skill to endorse on the lead's profile |
| `endorseAnyFallback` | boolean | `linkedinEndorse` | When `true` and the named skill is not on the lead's profile, lemlist falls back to endorsing any available skill |
| `recordMode` | string | `linkedinVoiceNote` | One of `manual` (user records the audio after step creation; default) or `ai` (audio is generated from a text template provided in the lemlist UI) |

<Note>
To remove the subject of an `email` step, send `"subject": ""`. The email then replies in the thread
of the previous email sent to the lead in this campaign instead of starting a new one.
</Note>

## Supported Condition Keys

For `conditional` steps:

- `hasEmailAddress`
- `hasLinkedinUrl`
- `hasPhoneNumber`
- `customLeadInfo`
- `hasScore`
- `emailsOpened`
- `emailsClicked`
- `emailsUnsubscribed`
- `meetingBooked`
- `linkedinInviteAccepted`
- `linkedinOpened`
- `aircallDone`
- `linkedinNetworkCheck`
- `hasWhatsappAccount`

A `customLeadInfo` step is patched with `customField` / `customOperator` / `customValue`; omitted
fields keep their stored value, so `{ "type": "conditional", "customValue": "CTO" }` changes the
tested value alone.
