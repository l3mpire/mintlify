---
openapi: get /call-statuses
description: Lists the team's call statuses (dispositions), the keys a logged call takes as callStatus.
---

The team's statuses are lemlist's defaults plus the ones the team added in **Settings → Calls**. Each one carries what the team configured it to do: count as answered, mark the lead as interested or not interested, pause campaigns. Pick the key when logging a call so the same automations run as when a rep picks the status in the dialer.
