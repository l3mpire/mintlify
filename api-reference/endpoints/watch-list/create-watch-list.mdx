<Note>
A Signal Agent is created as a draft by default. Pass `segmentType`, `signalProcessingType` and `activate: true` to run the full setup and start monitoring immediately. `filters` are validated against the chosen `type` — use [List allowed filters](/api-reference/endpoints/watch-list/get-filters) to discover which filters a type accepts.
</Note>

<Note>
Pass `campaignId` with `signalProcessingType: "push_to_campaign"` to link the new agent to that campaign as its signal trigger in the same call — same effect as [Add Signal Agent trigger](/api-reference/endpoints/campaigns/add-watch-list-trigger). If the call is refused (`400`, `404` or `409`), no agent is created. `campaignId` is not accepted by [Update Signal Agent](/api-reference/endpoints/watch-list/update-watch-list): to link an existing agent, use Add Signal Agent trigger.
</Note>

<Note>
For an external-signal agent (`externalSignalContact` / `externalSignalCompany`), map the keys your tool will push with the `externalSignalFieldMapping` filter, `in` being an array of `{ sourceKey, targetKey }` objects: `contact.linkedinUrl` is required for a contact agent, `company.domain` and `company.name` for a company agent. Extra keys to keep on each signal go in `externalSignalCustomFieldMapping`. Then push events with [Push external signals](/api-reference/endpoints/watch-list/push-external-signals).
</Note>

<Note>
For a `companyRunningAds` agent (companies advertising on LinkedIn, Meta, Google, TikTok or Apple), `maxIdentificationsPerDay` (`in`, one value, default 10) is required. Optional `in` filters: `adPlatforms` (`linkedin`, `facebook` for every Meta surface, `google`, `tiktok` — EEA, UK and Switzerland only —, `apple`; empty means all), `adFormats` (empty means all), `adTargetCountries` (country names), `adSearchTerms` (keywords matched on the ad title and description). `companyLocation`, `companyIndustries` (Pubrio vertical names, not the industries of the other company types: resolve them with [Autocomplete filter values](/api-reference/endpoints/watch-list/get-filter-values) using `type=companyRunningAds` and a `query`, and send the returned names verbatim — an unmatched value is a `400 WATCH_LIST_API_INVALID_FILTERS`, a Pubrio outage during validation a `503 WATCH_LIST_API_TAXONOMY_UNAVAILABLE`) and `companySizes` accept `in` and `out`; `companyLinkedinUrls` is `out` only. `crmListIds` is not accepted: attach CRM lists with [Associate CRM lists](/api-reference/endpoints/watch-list/associate-crm-lists) — a CRM list or CSV monitors the listed companies' domains only. Each signal costs 100 credits and a company is reported at most once per 30 days per agent; the agent moves to `insufficient_credits` when the team runs out and resumes on refill.
</Note>
