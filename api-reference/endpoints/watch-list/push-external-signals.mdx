<Note>
Create the external-signal agent from the lemlist app (Signal Agents → external signal) or with [Create Signal Agent](/api-reference/endpoints/watch-list/create-watch-list) (type `externalSignalContact` or `externalSignalCompany`). Its field mapping tells lemlist which key of your JSON body fills which field: push one flat JSON object keyed by those source keys, with Basic auth (empty username, API key as password) or `?access_token=<API key>` when your tool cannot set headers. The `contact` / `company` format below only applies to an agent without a field mapping. External signals are free (`creditsConsumed` is always `0`) and capped by the agent's daily limit (default 50/day); over the cap, or when no matching entity is found, the signal is returned with `status: "ignored"`.
</Note>
