<Note>
  The `updateStrategy` query parameter decides what happens to the values the lead, its contact and its company already hold: `overwrite` (default) replaces them and an empty value clears the field, `overwriteIgnoreEmpty` replaces them but never clears, `fillEmptyOnly` only fills the fields they have empty and keeps everything else (identifiers, company link, owner, status included). When the strategy keeps a value you sent (`fillEmptyOnly` on a filled field, or `overwriteIgnoreEmpty` ignoring an empty string on a filled field), the response lists it in `warnings` (`FIELDS_KEPT`, `params.fields`): lead variables by name, contact fields by name, company fields with their `company` prefix.
</Note>
