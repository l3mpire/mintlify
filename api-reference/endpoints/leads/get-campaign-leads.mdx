---
openapi: get /campaigns/{campaignId}/leads/
description: Retrieves leads from a specific campaign, optionally filtered by state.
---

<Note>
Leads are sorted by creation date (newest first), returned as `createdAt`: the date the lead was added to the campaign. Page through them with `limit` and `offset`. Use the `state` query parameter to filter leads by their current state (e.g., `scanned`, `contacted`, `interested`).
</Note>
